## 3. PROTECCIÓN DE RUTAS INTERNAS DJANGO ADMIN (`/admin/*`)

Las `167` rutas internas del panel nativo Django Admin (`/admin/*`) están gobernadas por `django.contrib.admin.sites.AdminSite` y endurecidas mediante `backend/apps/users/admin.py` (`UserAdmin`):

1. **Anti-escalada en `UserAdmin.get_readonly_fields`:** Ningún usuario que no sea `is_superuser=True` activo puede editar `is_superuser`, `is_staff`, `groups` ni `user_permissions` desde Django Admin.
2. **Protección de cuentas Super Admin en `UserAdmin.has_change_permission` y `has_delete_permission`:** Un usuario no-superusuario no puede modificar ni eliminar la cuenta de un superusuario.
3. **Protección del último Super Admin activo en `UserAdmin.save_model` y `has_delete_permission`:** Se impide desactivar, quitar `is_superuser` o eliminar al último Super Admin activo del sistema.
4. **Sincronización con ciclo de vida RBAC:** Cuando a un usuario administrativo se le revoca su último rol en LEVELPRO OS V4.0, `remove_role_from_user` sincroniza `is_staff=False` atómicamente, revocando también cualquier acceso al panel `/admin/`.
